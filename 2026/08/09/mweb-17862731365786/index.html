JCC 条件跳转指令入门

发表于2026-08-09|更新于2026-08-09|AI开发

基本概述

看反汇编代码时，经常会遇到 je、jne、jg、jl 这一类指令。它们都属于 JCC 指令，也就是条件跳转指令。

JCC 的全称可以理解为：

Jump if Condition is met

意思是：如果某个条件成立，就跳转到指定地址；如果条件不成立，就继续往下执行。

在逆向分析里，JCC 基本可以对应到高级语言里的 if、else、循环判断、错误分支判断。

1. JCC 指令是什么

JCC 由两部分组成：

J + CC

其中：

J  = Jump，跳转
CC = Condition Code，条件码

例如：

cmp eax, 1
je  success

可以读成：

比较 eax 和 1
如果相等，就跳转到 success

这里的 je 就是 Jump if Equal，相等则跳转。

2. JCC 判断的不是变量，而是标志位

JCC 指令本身不会直接比较两个变量。它判断的是 CPU 标志寄存器里的标志位。

常见标志位有：

标志位 名称 含义
ZF Zero Flag 结果是否为 0
CF Carry Flag 无符号运算是否产生借位或进位
SF Sign Flag 结果是否为负
OF Overflow Flag 有符号运算是否溢出
PF Parity Flag 结果低 8 位中 1 的个数是否为偶数

通常是前面的 cmp、test、sub 等指令先影响标志位，后面的 JCC 再根据标志位决定是否跳转。

最常见的组合是：

cmp eax, ebx
jne loc_fail

这段可以理解为：

如果 eax != ebx，则跳转到 loc_fail

3. cmp 和 JCC 的阅读方式

cmp a, b 本质上会做一次减法：

a - b

但它不会保存结果，只会更新标志位。

所以：

cmp eax, 10
je  equal

等价理解为：

if (eax == 10) {
    goto equal;
}

再看一个：

cmp eax, 10
jg  greater

如果这里按有符号数理解，就是：

if ((int)eax > 10) {
    goto greater;
}

重点是：同样是 cmp eax, 10，后面跟不同的 JCC，含义就不同。

4. 最常用的相等判断

相等和不相等判断主要看 ZF。

指令 条件 含义
JE / JZ ZF = 1 相等则跳转 / 结果为 0 则跳转
JNE / JNZ ZF = 0 不相等则跳转 / 结果不为 0 则跳转

JE 和 JZ 是同义指令，只是阅读角度不同：

cmp eax, ebx
je  same

更适合读成：

如果 eax == ebx，跳转

而：

test eax, eax
jz   is_zero

更适合读成：

如果 eax == 0，跳转

因为 test eax, eax 常用于判断一个值是否为 0。

5. 无符号数比较：看 A 和 B

无符号数比较时，常见指令里会出现 A 和 B：

A = Above，高于
B = Below，低于

它们用于无符号数比较。

指令 条件 含义
JA / JNBE CF = 0 且 ZF = 0 无符号大于
JAE / JNB CF = 0 无符号大于等于
JB / JNAE CF = 1 无符号小于
JBE / JNA CF = 1 或 ZF = 1 无符号小于等于

例如：

cmp eax, 100
ja  above_100

可以读成：

if ((unsigned int)eax > 100) {
    goto above_100;
}

无符号比较常见于长度、索引、内存大小、文件大小等场景。

6. 有符号数比较：看 G 和 L

有符号数比较时，常见指令里会出现 G 和 L：

G = Greater，大于
L = Less，小于

它们用于有符号数比较。

指令 条件 含义
JG / JNLE ZF = 0 且 SF = OF 有符号大于
JGE / JNL SF = OF 有符号大于等于
JL / JNGE SF != OF 有符号小于
JLE / JNG ZF = 1 或 SF != OF 有符号小于等于

例如：

cmp eax, 0
jl  negative

可以读成：

if ((int)eax < 0) {
    goto negative;
}

如果看到 jg、jge、jl、jle，优先按有符号整数比较理解。

7. 其他常见跳转

除了大小比较，还有一些直接检查标志位的跳转：

指令 条件 含义
JS SF = 1 结果为负则跳转
JNS SF = 0 结果非负则跳转
JO OF = 1 溢出则跳转
JNO OF = 0 没有溢出则跳转
JP / JPE PF = 1 奇偶校验为偶则跳转
JNP / JPO PF = 0 奇偶校验为奇则跳转

这些没有 je、jne、jg、jl 常见，但在编译器优化、特殊校验逻辑、底层库代码里也会遇到。

8. 逆向时怎么快速判断分支

看 JCC 不要只盯着跳转指令本身，应该往上看一两行，找到是谁设置了标志位。

常见阅读顺序：

  1. 找到 JCC 指令，例如 jne loc_fail。
  2. 往上找最近的 cmp 或 test。
  3. 判断比较对象，例如 cmp eax, 1。
  4. 把 JCC 翻译成高级语言条件。
  5. 看跳转目标是成功分支还是失败分支。

例如：

cmp eax, 1
jne loc_fail
mov ecx, 1234h
jmp loc_end

loc_fail:
xor ecx, ecx

可以整理成：

if (eax != 1) {
    ecx = 0;
} else {
    ecx = 0x1234;
}

注意这里 jne loc_fail 跳向的是失败分支，所以不能只看到 jne 就机械理解成“主逻辑是不相等”。要结合跳转目标一起看。

9. test reg, reg 的常见用法

test 指令经常和 jz、jnz 搭配：

test eax, eax
jz   loc_zero

test eax, eax 会把 eax 和自身做按位与。如果 eax 是 0，结果就是 0，ZF 会被置 1。

所以它常被用来判断：

if (eax == 0) {
    goto loc_zero;
}

另一个常见形式：

test eax, eax
jnz  loc_not_zero

等价于：

if (eax != 0) {
    goto loc_not_zero;
}

在函数返回值判断里，这种写法非常常见。

10. 一张速查表

下面这张表可以作为日常读汇编时的完整速查表。重点看两列：一列是它检查哪个标志位，另一列是它适合有符号还是无符号语义。

JCC 指令 中文含义 检查标志位 英文全称
JE / JZ 结果为零则跳转，也常用于相等时跳转 ZF = 1 Jump if Equal / Jump if Zero
JNE / JNZ 结果不为零则跳转，也常用于不相等时跳转 ZF = 0 Jump if Not Equal / Jump if Not Zero
JS 结果为负则跳转 SF = 1 Jump if Sign
JNS 结果非负则跳转 SF = 0 Jump if Not Sign
JP / JPE 结果中 1 的个数为偶数则跳转 PF = 1 Jump if Parity / Jump if Parity Even
JNP / JPO 结果中 1 的个数为奇数则跳转 PF = 0 Jump if Not Parity / Jump if Parity Odd
JO 结果溢出则跳转 OF = 1 Jump if Overflow
JNO 结果没有溢出则跳转 OF = 0 Jump if Not Overflow
JB / JNAE 小于则跳转，按无符号数理解 CF = 1 Jump if Below / Jump if Not Above or Equal
JNB / JAE 大于等于则跳转，按无符号数理解 CF = 0 Jump if Not Below / Jump if Above or Equal
JBE / JNA 小于等于则跳转，按无符号数理解 CF = 1 或 ZF = 1 Jump if Below or Equal / Jump if Not Above
JNBE / JA 大于则跳转，按无符号数理解 CF = 0 且 ZF = 0 Jump if Not Below or Equal / Jump if Above
JL / JNGE 小于则跳转，按有符号数理解 SF != OF Jump if Less / Jump if Not Greater or Equal
JNL / JGE 大于等于则跳转，按有符号数理解 SF = OF Jump if Not Less / Jump if Greater or Equal
JLE / JNG 小于等于则跳转，按有符号数理解 ZF = 1 或 SF != OF Jump if Less or Equal / Jump if Not Greater
JNLE / JG 大于则跳转，按有符号数理解 ZF = 0 且 SF = OF Jump if Not Less or Equal / Jump if Greater

记忆时可以抓住两个重点：

A / B 用于无符号比较
G / L 用于有符号比较

相等判断则主要看：

E / Z 表示相等或结果为零
NE / NZ 表示不相等或结果不为零

11. 总结

JCC 条件跳转并不复杂，它的核心就是：

  1. 前面的指令先设置标志位。
  2. JCC 根据标志位决定是否跳转。
  3. JE/JNE 看是否相等。
  4. JA/JB 这组用于无符号比较。
  5. JG/JL 这组用于有符号比较。

逆向时读 JCC，最重要的是把 cmp/test + jcc + 跳转目标 连起来看。只要能判断“跳转条件是什么”和“跳过去之后走哪条分支”，大部分 if、else、循环判断就能还原出大致逻辑。
